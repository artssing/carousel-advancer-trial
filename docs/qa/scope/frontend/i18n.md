- [IN-02] `curl` `verified` — 切換語言 → `/api/locale?lang=X&from=…` set cookie 再 full reload
  - `curl -s -o /dev/null -D - "https://uat.certifinehk.com/api/locale?lang=en&from=/browse"`
  - 實測 2026-08-03，三個 portal（`uat` / `uat-auth` / `uat-admin`）全部：
    **307** + `Set-Cookie: lang=en; Path=/; Max-Age=31536000; SameSite=lax` + `Location:` 指返 `/browse`
  - ⚠️ 三個 portal 都收 `from=/browse` 然後照跳，即使 `/browse` 只喺 consumer 存在
    （authenticator / admin 會跳去自己 domain 嘅 `/browse`）。呢個未有 ruling，只記錄。
  - 理由：cookie + full reload 係定咗嘅機制（唔行 client-side i18n context），
    改成 SPA 切換會令 server-rendered meta 對唔上語言

- [IN-03] `browser` `unverified` — 已 wire 嘅頁真係轉曬文
  - 未有 Playwright spec。範圍：consumer top-nav / footer / browse；authenticator login / dashboard / scan / inbox
  - 驗法：set `lang=en` cookie 之後睇 rendered 內容
  - 理由：key 存在唔等於 component 有用佢；混雜中英係最常見嘅 i18n 半成品狀態

- [IN-05] `static` `verified` — 改完 `locales/ssot.json` 要行 `npx tsx scripts/compile-locales.ts` 再 rebuild utils
  - `python3 -c "import json;print(json.load(open('packages/utils/package.json'))['scripts'])"`
  - 實測 2026-08-03：`{'compile-locales': 'npx tsx ../../scripts/compile-locales.ts',
    'build': 'tsc -p tsconfig.build.json', 'type-check': 'tsc --noEmit'}` —— `build` **冇**夾 `compile-locales`
  - ⚠️ `packages/utils/package.json` 個 `build` script **唔可以**加 `compile-locales`
    （`scripts/` 唔喺 Docker image 入面，會炸 `ERR_MODULE_NOT_FOUND`）
  - 理由：呢條係「唔好順手優化」嘅守門員 —— 兩個 script 分開係有原因嘅
